## Feature currency review — 2026-10-17

This review records concrete retain/defer decisions against the current implementation and upstream documentation. It does not imply that a feature is safe merely because the code path is present, nor that optional provider evaluations ran.

| Capability | Current implementation | Official support checked | Benefit and compatibility risk | Decision and proof |

| Python and uv runtime selection | Python 3.12 and 3.13 are supported. The PR-gate job sets `UV_PYTHON` from the active matrix leg so each `uv run` remains on the interpreter installed for that leg. | [uv Python version selection](https://docs.astral.sh/uv/concepts/python-versions/) documents interpreter selection and project pin behavior. | The matrix exercises both supported runtimes. Runtime drift from an unconstrained `uv` version can still change resolution/behavior; changing the Python versions requires lock and native CI checks. | **Retain 3.12/3.13; fix matrix selection.** Exact PR Gate `39028982517` at `c37c41b` passes both runtimes through lint, format, mypy, tests, coverage and hermetic evidence generation. Its later dependency-audit steps fail on unresolved advisories, tracked under R02. |
| Local vector retrieval and embedding | Candidate branch uses FastEmbed `0.9.0` with the same local ONNX model (`sentence-transformers/all-MiniLM-L6-v2`) and stores normalized vectors/chunk metadata in a transactional SQLite index keyed by corpus fingerprint and embedder version. No vector network service is started. | FastEmbed's [PyPI release record](https://pypi.org/project/fastembed/) reports `0.9.0`; its [supported-model catalog](https://qdrant.github.io/fastembed/examples/Supported_Models/) lists the same MiniLM model. | SQLite-backed brute-force cosine search is appropriate for this 62-chunk fictional corpus, not a large index. Model files still require a first-run download and are cached locally. The branch's local full-corpus probe matched all 16 old ordered chunk results; local hosted-style checks still need final CI/image confirmation. | **Replace Chroma with FastEmbed/SQLite if the full hosted matrix, packaged Tier-1 suite and security scans pass.** Chroma's four advisory IDs are removed from active ignore files; `.trivyignore` has no active suppressions. |
| Tool schema and authorization boundary | The assistant exposes one coverage-calculator schema, validates its arguments in target-owned code, rejects unexpected/multiple calls, and keeps synthetic member authorization in the application/API rather than trusting model-selected identity. | [Pydantic model validation](https://docs.pydantic.dev/latest/concepts/models/) is used for typed request/response data; the shared reference application's API checks member-scoped access independently of the assistant. | Explicit schemas and server-side scope reduce hallucinated tool and cross-member access risk. More autonomous agent loops would add state, provider variance and extra authorization paths. | **Retain the single-round bounded tool. Defer agent-framework adoption.** Shared-app run `39028982451` passes pinned-image startup, member-isolation and citation retrieval with a stubbed provider; it makes no live model-quality claim. |
| Semantic and adversarial evaluation | Semantic evaluation is optional and separates replay from provider calls. The lock resolves DeepEval and RAGAS; RAGAS adapters use the legacy `ragas.metrics` path and contain a compatibility shim. Promptfoo live red-team runs are separate from hermetic adversarial tests. | RAGAS [current metric catalog](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/) includes RAG and tool-use metrics; the [RAGAS PyPI release record](https://pypi.org/project/ragas/) was checked on this review date. | New metric collections and agent/tool metrics could broaden measurement, but the newer RAGAS import/adapter shapes require a real compatibility run. The old Python/image scan results are historical and do not verify the new lock or image. **R02 remains in progress** until both Python matrix jobs, pip-audit, packaged tests, Trivy and a human review of the two remaining proposed exceptions complete on the same final head.
